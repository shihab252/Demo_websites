# 🧩 Project Architecture

Most projects are developed using a component-based architecture.

A typical project structure looks similar to:

```text
project/
│
├── public/
│
├── src/
│   ├── assets/
│   ├── components/
│   ├── sections/
│   ├── data/
│   ├── hooks/
│   ├── utils/
│   ├── App.jsx
│   └── main.jsx
│
├── package.json
├── tailwind.config.js
├── vite.config.js
└── README.md
